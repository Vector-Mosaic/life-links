# WebMCP Challenge work boundary

Life Links is a pre-existing full-stack application. The public baseline commit
contains the existing human QR, notes, project, search, Find Mode, rich-editor,
privacy, authentication, and Postgres capabilities before WebMCP product work.

The generated `SOURCE_PROJECTION.json` binds the admitted application source to
an exact canonical commit, canonical and projected source-tree SHA-256 values,
and every fail-closed public-release transform. The root files package that
projection as a standalone repository and are outside this baseline source
digest.
Subsequent entries will map each new WebMCP and recursive-hierarchy checkpoint
to its canonical commit, public commit, verification, and deployed revision.

| Capability | Existing before challenge | Challenge extension | Evidence |
|---|---:|---:|---|
| QR resolution and claim | Yes | No | Baseline source and tests |
| Owner notes, privacy, media, search, and Find Mode | Yes | No | Baseline source and tests |
| Recursive Life Link hierarchy | No | Planned | Pending implementation commit |
| Page-bound WebMCP tools | No | Planned | Pending implementation commit |
| Agent draft with human Save | No | Planned | Pending implementation commit |

The final entry will preserve this distinction rather than presenting existing
work as hackathon-created work.
